[CONCETTO] Modello dei Permessi POSIX (rwx, UGO e Notazioni)
• In Linux ogni file e directory è regolato da 3 livelli di accesso:
  - User/Owner (u): proprietario del file.
  - Group (g): gruppo a cui appartiene il file.
  - Others (o): tutti gli altri utenti del sistema.
• I 3 permessi base corrispondono a valori numerici ottali:
  - Read (r) = 4
  - Write (w) = 2
  - eXecute (x) = 1
• Esempi:
  - 600 = (4+2) / 0 / 0 = rw------- (solo il proprietario può leggere e scrivere).
  - 775 = (4+2+1) / (4+2+1) / (4+1) = rwxrwxr-x (owner e gruppo controllo completo, altri sola lettura e accesso).
• Nota fondamentale: su una directory, il bit 'x' (eseguibile) serve per poter entrare nella cartella e accedere ai suoi file.
• Su una directory: r elenca i nomi, w crea/rimuove voci, x permette di attraversarla e accedere agli elementi.
---
[STRATEGIA & BEST PRACTICES]
• Posizione di lavoro: assicurati di trovarti in '/workspace/training/@V_DIR@' (usa 'pwd').
• Per aggiungere il bit di esecuzione senza modificare gli altri bit usa 'chmod a+x'; non è sempre equivalente a impostare 755.
• Per impostare permessi rigidi e precisi (come 600 per file privati o 775 per cartelle condivise), la notazione numerica 'chmod <modo> <bersaglio>' è la più rapida e sicura.
• Crea la cartella prima di impostarne i permessi e scrivervi all'interno il file @V_DBOX_README@.
---
[COMANDI GUIDATI & ALTERNATIVE]
1. Bit eseguibile per tutti:
   chmod a+x @V_SCRIPTS@/@V_SCRIPT@
   (valide anche: chmod +x @V_SCRIPTS@/@V_SCRIPT@  oppure  chmod 755 @V_SCRIPTS@/@V_SCRIPT@)

2. File privato (solo proprietario):
   chmod 600 @V_PRIVATE@

3. Creazione directory e permessi di gruppo:
   mkdir -p @V_DROPBOX@
   chmod 775 @V_DROPBOX@

4. Scrittura del file nel posto corretto:
   printf '@V_TEXT@\n' > @V_DROPBOX@/@V_DBOX_README@
   oppure:
   echo '@V_TEXT@' > @V_DROPBOX@/@V_DBOX_README@
Nota di sicurezza: controlla sempre il percorso con pwd e ls; non usare chmod -R in questo esercizio.
