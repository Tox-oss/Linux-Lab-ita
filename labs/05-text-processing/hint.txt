[CONCETTO] Flussi di Testo Unix, Pipeline, Filtri e Colonne
• La filosofia Unix si basa su strumenti specializzati che elaborano flussi di testo collegati tra loro tramite pipe '|'.
• 'grep': cerca e filtra le righe corrispondenti a una stringa o espressione regolare.
• 'wc -l' (word count lines): conta il numero di righe ricevute nello stream.
• 'sort': ordina le righe alfabeticamente o numericamente; con '-u' (unique) elimina i duplicati ordinando in un solo colpo.
• 'awk': processore di testo strutturato a colonne.
  - Per impostazione predefinita divide per spazi bianchi ($1, $2, $3...).
  - Con '-F,' imposta la virgola come separatore di campo (ideale per file CSV).
  - 'NR > 1' ignora la prima riga (header).
  - Il blocco 'END { ... }' viene eseguito una sola volta al termine della lettura del file.
• Prima di scegliere i campi, guarda esempi reali con 'head -n 5 @V_LOG@' e 'head -n 5 @V_CSV@'.

[COMANDI GUIDATI & ALTERNATIVE]
1. Conteggio righe di errore:
   grep 'ERROR' @V_LOG@ | wc -l > @V_OUT1@

2. IP con status HTTP 500 (ordinati e unici):
   awk '$4 == 500 { print $1 }' @V_LOG@ | sort -u > @V_OUT2@

3. Somma della colonna requests per il servizio 'api':
   awk -F, 'NR > 1 && $1 == "api" { sum += $3 } END { print sum }' @V_CSV@ > @V_OUT3@

4. File summary:
   printf '@V_TEXT@\n' > @V_OUT4@
   oppure:
   echo '@V_TEXT@' > @V_OUT4@
